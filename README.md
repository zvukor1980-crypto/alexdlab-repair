# RepairLab

Интерактивная инженерная база диагностики электроники для GitHub Pages.

## Возможности

- категория → производитель → модель → неисправность;
- пошаговый диагностический flow;
- список требуемых приборов;
- привязка сервисных документов;
- локальные заметки мастера;
- помощник измерений без выдумывания контрольных норм;
- PWA/offline-кэш;
- расширяемая JSON-база.

## Важно

Точные test points, номиналы, напряжения, осциллограммы, температуры и BGA-профили должны добавляться только при наличии проверенного сервисного источника для конкретной модели и ревизии платы.

## Публикация

GitHub Pages публикуется автоматически из `main` через `.github/workflows/pages.yml`.
