# RepairLab

Интерактивная инженерная база диагностики электроники для GitHub Pages.

## Возможности

- категория → производитель → модель → неисправность;
- пошаговый диагностический flow;
- список требуемых приборов;
- привязка сервисных документов;
- локальные заметки мастера;
- помощник измерений без выдумывания контрольных норм;
- PWA/offline-кэш;
- расширяемая JSON-база.

## Важно

Точные test points, номиналы, напряжения, осциллограммы, температуры и BGA-профили должны добавляться только при наличии проверенного сервисного источника для конкретной модели и ревизии платы.

## Публикация

GitHub Pages публикуется автоматически из `main` через `.github/workflows/pages.yml`.

## Заметки, отметки диагностики и отчёт

Заметки сохраняются автоматически через 250 мс после ввода и при смене модели или закрытии страницы. Ключ включает категорию, производителя и модель. Старые заметки переносятся при первом выборе соответствующей модели; исходная запись сохраняется. Если запись недоступна, черновики остаются в памяти открытого приложения даже при переключении моделей. До закрытия приложения нужно повторить сохранение или скачать отчёт.

Отметки «Выполнено» и «Есть отклонение» сохраняются отдельно для устройства и неисправности. Повторное нажатие убирает отметку. Кнопки «Скачать отчёт» и «Печать / PDF» включают выбранную модель, неисправность, шаги и заметки. Это локальный HTML-отчёт без сетевых зависимостей; PDF создаётся через системное окно печати.

Повреждённое сохранение чек-листа не останавливает интерфейс. Ошибки записи показываются под заметками. При смене устройства старые диагностические шаги и документы очищаются.

`npm install` и `npm test` (Node 24+) проверяют перенос заметок, раздельное сохранение, переключение контекста, отметки, ошибку записи и повтор, безопасное отображение текста отчёта в эмуляции DOM. Проверка скачивания и печати на физическом iPhone ещё нужна.
