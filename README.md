# AlexDLab Repair

Стартовая версия базы ремонта iPhone 5.

## Быстрый запуск локально

```bash
cd public
python3 -m http.server 8000
```

Открыть: http://localhost:8000

## Публикация

```bash
./deploy.sh
```

## Важно

Папка `source-materials/` содержит исходные сервисные материалы и исключена из GitHub и автоматической публикации.
Публиковать полные сторонние схемы следует только при наличии соответствующих прав.
